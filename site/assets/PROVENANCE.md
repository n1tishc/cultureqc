# Raster provenance

The shipped artifact is the Vite build in `site/dist`, whose reference images are copied into
`site/public/img/` by `build_data.py`. Nothing in this directory is served directly; these are
the build inputs those scripts read. **No raster anywhere in this project was generated by an
image model.** Every one is either real microscopy, a deterministic output of this
repository's own pipeline, or a screenshot of markup this repository writes.

| Files | Origin |
|---|---|
| `pipeline-output/{A172,BT474,BV2,Huh7}_base.png` | Real phase-contrast microscopy from `test-data/*.tif` (LIVECell-derived), converted to PNG and min-max normalised by `regen.py`. Unaltered otherwise. |
| `pipeline-output/{contam,detach,imgq,normal}_base.png` | The repository's existing 256×256 challenge tiles in `test-data/`, produced earlier by `scripts/synth_contamination.py`. Copied, not re-synthesised. |
| `pipeline-output/Huh7_contaminated_field.png` | The real Huh7 field with bacterial sprites composited in by `scripts/synth_contamination.py::add_bacteria` at the early-severity rung, once per 256×256 tile-area of the full 704×520 frame, seed `numpy.random.default_rng(7)`. Sprites from `data/sprites/bacteria` (DeepBacs), used at their source optical scale. |
| `pipeline-output/*_mask.png` | Cellpose-SAM cell-probability masks, thresholded at `flows[2] > 0`, written by `regen.py`. Model output, not drawn. |
| `ladder/{line}_{clean,early,mid,late}.png` | Four real fields centre-cropped to 256×256, with sprites composited at the named severity by `scripts/synth_contamination.py`, seed `numpy.random.default_rng(42)`. Native sprite scale. |
| `web/*.webp` | Lossy (q 74–78) or lossless-with-alpha WebP conversions of the above, by `prep_assets.py` via `cwebp`. No retouching. |
| `src/assets/fonts/archivo-latin.woff2` | Google Fonts, latin subset, variable (weight + width): Archivo (Omnibus-Type). SIL Open Font License 1.1. The language voice — headings, figures, prose, controls, wordmark. |
| `src/assets/fonts/plexmono-latin.woff2`, `…-600.woff2` | Google Fonts, latin subset: IBM Plex Mono (Mike Abbink / Bold Monday, IBM). SIL Open Font License 1.1. The machine hand — record fields, hashes, labels, table headers, measured data. |
| `public/og.png`, `public/favicon.png` | Rendered by `make_og.py`: a headless Chromium screenshot of markup in that script. The field, segmentation mask, evidence box, readouts and record fields are read out of `pipeline-output/results.json` and `public/img/`; the logomark is authored SVG in the same script. Not an image-model output, and not retouched. |

Every number, mask, evidence box and hash the page displays came out of `culture/*` on this
machine. The `events.jsonl` in `pipeline-output/` is the real hash-chained log written by
`culture.records.RecordWriter`; the page recomputes those digests in the browser.
